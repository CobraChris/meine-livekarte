# Permanent Android launcher — release candidate
This independently installed APK launches the existing Livekarte URL in Google Chrome in the same Android user/profile. It has a normal MAIN/LAUNCHER entry, fixed package ID and its own map icon. It contains no WebView, INTERNET permission, storage, sync credentials or configurable URL. The webpage and its existing PWA remain unchanged; Chrome owns the website's data. Do not clear browser data or uninstall the old PWA before testing. If Chrome is unavailable, show an explicit error rather than silently switching storage profiles. The launcher does not itself implement Android share targets; the existing PWA must remain available for those features.

Build: existing App Factory Android check (Gradle 8.11.1/JDK 17, project_path android-launcher, module app). Add the approved CI integration and use a separately provisioned stable signing identity for this package before distributing any production APK. No debug APK as permanent installation. Native install/launch and same-profile website data access on Samsung, including the existing ticket functions, must be verified by the owner. Native package updates and One UI home layout are separate from Pages updates; uninstall, reset or manually moving an icon can still remove it.
